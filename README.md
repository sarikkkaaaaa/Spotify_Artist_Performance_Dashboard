# 🎧 Spotify Artist Performance Dashboard

### 📊 Artist Performance | Streaming Trends | Genre Analysis | Geography

---

## 📌 Project Overview

The **Spotify Artist Performance Dashboard** is an interactive Power BI project designed to analyze the streaming performance of 500 Spotify artists.

The dashboard transforms raw artist-level data into meaningful visual insights across artist type, gender/sex, genre, country of origin, debut year, and collaboration performance.

The project focuses on identifying top-performing artists, understanding streaming patterns, and exploring the factors contributing to overall streaming performance.

---

## 🎯 Business Objective

The primary objective of this project is to provide an interactive analytical view of Spotify artist performance and answer key business questions such as:

- Which artists have the highest total streams?
- Which genres generate the most streams?
- How does streaming performance differ between solo artists and groups?
- What percentage of streams comes from collaborations?
- Which countries contribute the most to total streams?
- How does artist performance vary by sex?
- Which debut decades have produced the highest streaming performance?
- Which genres have the highest average streams per artist?

The dashboard enables users to explore these questions dynamically using interactive filters.
